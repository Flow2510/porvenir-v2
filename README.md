# 🌿 Jungle Lodge Website

A modern and immersive website for a jungle lodge located near Santa Marta, Colombia.

The project focuses on creating a premium digital experience that reflects the atmosphere of the lodge: nature, adventure and relaxation.

## ✨ Features

- Responsive design for mobile, tablet and desktop
- Accommodation showcase with detailed rooms information
- Image galleries with responsive images
- Activities and local experiences section
- Customer reviews section
- Smooth animations and interactive UI
- Optimized images using WebP format
- Modern dark nature-inspired design

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Swiper.js
- Vite
- Font Awesome

## 📱 Responsive Design

The website is optimized for:

- Mobile devices
- Tablets
- Desktop screens

Images are served using responsive formats to improve loading performance.
